- Chat animé (fenêtre transparente GDI+) : il suit la souris, cligne des yeux, réfléchit et saute de joie à la fin. On peut le glisser et y déposer des fichiers.
- Discussion (WebView2, `ui.html`) : markdown, étiquettes d'outils, détail des changements, autorisation avant les commandes (`permission_denials` → `--allowedTools`), mode autonome (`bypassPermissions`), reprise de session (`--resume`).
- Centre de contrôle (`settings.html`) : nom, taille, affichage, premier plan, modèle, instructions personnalisées, démarrage auto, lancement de Claude Code (nouvelle session ou reprise de celle du chat).
- Raccourci Ctrl+Alt+C, icône dans la zone de notification, entrée « Bébène » dans le menu Démarrer.

## Règles
- Bébène ne peut PAS se modifier lui-même : chaque conversation de Bébène charge `garde-settings.json` (hook PreToolUse `garde.ps1`, dans %LOCALAPPDATA%ClaudeCompanion) qui bloque toute écriture/commande visant claude-companion, ClaudeCompanion (install, registre, données). Seul Claude Code dans le terminal fait évoluer Bébène. Le projet est masqué du menu des projets de Bébène.
- Paquet à partager : double-clic sur `Créer le paquet Bébène.cmd` (script `creer-paquet.ps1`) → `paquets/Bebene-<version>-<date>.zip` (app compilée + hub-modele sans infos perso + LISEZMOI). L app n a plus de bouton d export.
- À CHAQUE nouvelle fonction ou amélioration visible de Bébène : ajouter ou mettre à jour son entrée dans `fonctions.json` (cat, titre, depuis = version, desc, ex = exemple concret). Les réglages l affichent automatiquement (« Ce que Bébène sait faire », badge « Nouveau » pour la version en cours).

## Fichiers
- Source (ici) : `Companion.cs`, `ui.html`, `settings.html`, `build.ps1`.
- Installation locale : `~/ClaudeCompanion/` (exe, DLL WebView2, copies des fichiers HTML). Réglages : `HKCU\Software\ClaudeCompanion`.
- Après une modification de la source : `build.ps1` (ajouter `-Install` sur un nouveau PC).

## Technique
- Compilé avec `csc.exe` de .NET Framework 4 (C# 5 : pas de `?.`, de `$""` ni de `nameof`), sans SDK.
- WebView2 1.0.2903.40, téléchargé depuis NuGet par `build.ps1`.

- Dépôt GitHub (public) : https://github.com/P0770/bebene — après une évolution : `git add -A; git commit -m "..."; git push`.
